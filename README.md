# Itaberry

Itaberry is a program combining a web interface, and SPI displays controllers, running on a Raspberry Pi 4B. 
It was designed as a way to have animated/changeable pins on an "Itabag".

Frontend uses Svelte, SPI displays are controlled using Rust and Raspberry Pi GPIO. To connect all the displays nicely, a custom PCB was designed.
